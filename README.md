# 🗂️ Rock, Paper, Scissors Game ✊🖐️✌️ 
This Rock, Paper, Scissors game is a simple browser-based project built with HTML, CSS, and JavaScript. The interface lets the user choose Rock, Paper, or Scissors, and the game then generates a computer choice.

## ✅ Key Features
- Play against the computer (Rock, Paper, Scissors).
- hows the result after each round: Win / Lose / Draw.
- Simple, interactive UI with buttons for each choice.
- Clean game logic using conditionals and reusable functions.
## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript:

   - Conditionals to determine the winner
   - Functions to structure the game logic
   - getElementById to access buttons and result area


## ▶️ How to Run
Open `index.html` in your browser.
